Unity classroom project for human-computer interaction and game interfaces.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Credits.unity](https://github.com/kleberandrade/aulas-ihc-unity/blob/main/Assets/Scenes/Credits.unity), [Assets/Scenes/Menu.unity](https://github.com/kleberandrade/aulas-ihc-unity/blob/main/Assets/Scenes/Menu.unity), [Assets/Scenes/Press Start.unity](https://github.com/kleberandrade/aulas-ihc-unity/blob/main/Assets/Scenes/Press%20Start.unity), [Assets/Scenes/SampleScene.unity](https://github.com/kleberandrade/aulas-ihc-unity/blob/main/Assets/Scenes/SampleScene.unity).
